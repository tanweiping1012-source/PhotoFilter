# 旅行照片筛选器隐私政策

最后更新：2026 年 8 月 18 日

旅行照片筛选器是一款本地优先的 macOS 照片筛选工具。本政策说明 App 如何处理照片、项目状态和可选 AI 请求。

## 1. 本地照片处理

- App 只读取用户通过 macOS 文件夹选择器明确授权的目录。
- 缩略图、拍摄时间、感知哈希、相似分组、技术质量提示，以及 Apple Vision 人物主题判断（人体、人脸质量、人物分割和显著性）均在本机处理。
- App 不会删除、移动、覆盖、改名或写回原照片。
- 导出仅复制用户标记为保留的照片，分别放入人物和风景子目录，并在用户选择的目标目录生成 `selection.json` 和 `selection.csv`。导出目录不能选在原照片文件夹内部。

## 2. 本机保存的数据

为恢复筛选项目，App 在沙盒 Application Support 目录中保存：

- 只读 security-scoped bookmark；
- 可读项目名称、照片数量和最近打开时间；
- 人物与风景的保留目标；
- 当前选中照片的相对路径；
- 用户明确作出的保留或淘汰决定。
- 用户明确纠正的人物或风景类型。

App 不持久化原照片、缩略图、感知哈希、自动人物主题证据、技术分析结果、AI 上传预览或 AI 原始响应。

用户为火山方舟、MiniMax、OpenAI、Anthropic、Google、阿里云百炼、xAI、Kimi、智谱、腾讯混元或自定义兼容接口提供的 API Key 使用相互隔离的 macOS Keychain 条目。Key 不会写入项目文件、UserDefaults、日志、诊断信息、导出目录或测试数据。

## 3. 可选 AI评分

AI 功能默认不发送数据。只有用户选择品牌和模型、配置对应供应商 API Key、查看发送说明并在每次运行前确认后，App 才会发起请求。

每次请求只向本次选择的一个服务发送。内置端点包括：

- 火山方舟北京区域 Responses API；
- MiniMax 中国区 `api.minimaxi.com`；
- OpenAI `api.openai.com`；
- Anthropic `api.anthropic.com`；
- Google Gemini `generativelanguage.googleapis.com`；
- 阿里云百炼 `dashscope.aliyuncs.com`；
- xAI `api.x.ai`；
- Kimi `api.moonshot.ai`；
- 智谱 `open.bigmodel.cn`；
- 腾讯混元 `api.hunyuan.cloud.tencent.com`；
- 用户在高级设置中明确保存的自定义 OpenAI-compatible endpoint。

发送内容为：

- 每次请求 1 张 JPEG 预览，最长边由用户选择为小 512px、中 1024px 或大 1536px；
- 本次请求内有效的 `photo_001` 等匿名照片 ID；
- AI评分指令；
- 用户自己的所选供应商 API Key，作为 HTTPS 鉴权请求头；本机回环自定义接口可使用 HTTP。

App 不会向任何供应商发送原始照片文件、原始文件名、本地路径或 EXIF/GPS 元数据。预览在内存中重新编码，不写入磁盘。AI 请求使用独立的临时网络会话：不写入磁盘缓存，不保存 Cookie 或网络凭据，因此供应商响应与会话状态不会留在这台 Mac 上。默认小 512px；中或大可能增加上传量、响应时间和供应商费用。方舟请求设置 `store=false`；MiniMax 请求关闭思考；其他协议只解析通过本地契约校验的工具参数或 JSON。

用户点击“验证并保存”或“验证已保存的 Key”时，App 会向当前选择的模型发送 1 张 App 内置测试图，验证 API Key、账号权限、模型、图片输入和评分契约。测试图不是用户照片；验证可能产生少量供应商费用。新 Key 仅在验证成功后写入 Keychain。

用户点击“刷新账号模型”时，App 会使用当前输入或已保存的 OpenAI / Anthropic Key 调用对应模型列表接口，只读取账号可见的模型 ID 和显示名。该请求不发送任何图片，返回的模型列表不持久化；用户选中的其他 model ID 作为非敏感配置保存在 UserDefaults，并仍需经过上述图片连接验证。

尽管图片使用匿名照片 ID，所选供应商仍可通过 API Key 将请求关联到对应账号。供应商或自定义接口运营方对请求、安全日志和账号数据的处理受用户与该服务之间适用的条款和隐私规则约束。App 不会把同一组预览同时发送给多个服务。

模型响应在本机经过版本、候选范围、匿名 ID、分数、五维评价和理由范围校验。AI 结果只作为建议，不会自动保留、淘汰、移动或导出照片。

## 4. 跟踪、广告和分析

App：

- 不包含广告 SDK；
- 不包含第三方分析 SDK；
- 不进行跨 App 或网站跟踪；
- 不收集广告标识；
- 不收集位置、联系人、健康、支付或浏览历史；
- 不建立旅行照片筛选器用户账号。

## 5. 数据删除与用户控制

- 在 App 中删除项目，会移除对应项目状态并释放缩略图缓存，不会删除原照片。
- 在 AI评分设置中可分别删除供应商 API Key，对应 Key 会从当前 Mac 的 Keychain 删除。
- 导出内容位于用户选择的目录，由用户自行管理或删除。
- 卸载 App 后，macOS 可能保留 Keychain 项；用户可在卸载前先通过 AI 设置删除 Key。

## 6. 数据安全

App 使用 macOS App Sandbox、security-scoped bookmark 和 Keychain 限制本地访问。AI 请求通过 HTTPS 发送，并在发送前最小化图片尺寸与元数据。

## 7. 政策更新

若数据处理方式发生变化，本政策和 App 内“隐私与数据”说明将同步更新，并修改顶部日期。

## 8. 联系方式

隐私或支持请求请通过 App Store 产品页中公布的“App 支持”链接联系开发者。正式发布前，该链接必须指向可公开访问的支持页面。
