# PC-39 统一完整 AI评分入口验收

## 目标

- 移除“AI评分相似照片”局部评分按钮。
- 人物与风景各自只通过侧栏中的完整候选池入口开始 AI评分。
- 避免局部评分和完整评分产生重复发送确认、重复费用认知和两套结果语义。

## 实现

- 主界面和大图预览不再显示局部评分按钮。
- 删除局部评分确认弹窗、任务状态、请求方法和只服务于该流程的 ViewModel 属性。
- 删除 `AestheticReviewGroupPlanner`、`AestheticReviewRunPlanner` 及对应旧测试。
- 完整评分继续复用匿名 ID、无元数据 JPEG、供应商适配器、严格响应校验和类别内全局排序。

## 验收

- 主界面仍存在 `prepareAIFinalSelectionRun()` 完整评分入口。
- Swift 源码、String Catalog 和 Xcode 工程均不再包含局部评分入口或旧规划器。
- 大图预览继续支持连续浏览、人工决定、相似照片位置、技术风险和完整评分结果查看。
