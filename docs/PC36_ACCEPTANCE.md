# PC-36 人物与风景分开筛选验收

## 交付结果

- 主界面增加“全部 / 人物 / 风景”三段选择，与原有照片状态筛选独立组合。
- Apple Vision 在本机组合完整人体、人脸质量、人物分割、实例数量和显著性；只有人物承担主要视觉主题时归为人物，远处路人和背景人群归为风景。
- 照片卡显示人物/风景标签；卡片菜单和大图均可人工纠正，纠正值按相对路径持久化并优先于后台分析。
- 保留目标拆为人物和风景两行，默认 6/6，可分别设为 0–999；旧项目总目标迁移后总数保持不变。
- 人物和风景分别形成待评分池、评分 scope、运行进度、失败状态、分类内排序和评分优先集合。
- 人物 Prompt 关注表情、姿态、互动和环境关系；风景 Prompt 关注空间层次、构图、光线、氛围和地点叙事。
- 一次导出同时校验两类目标，并在同一时间戳目录中创建“人物”和“风景”子目录及带类别的根清单。
- 新手引导升级为八步，样例为 4 张人物和 4 张风景，继续使用动态红框、小指针和正常结束主按钮。

## 安全与迁移

- 自动分类不联网、不读取 Keychain、不写入原图，也不持久化自动检测结果。
- 人工分类纠正不会改变保留或淘汰决定；修改类型会清除过期分类评分结果，防止旧类别分数进入新类别排序。
- AI 请求继续只发送 2–5 张同类型的匿名无元数据 JPEG，不发送原图、文件名、路径或 EXIF/GPS。
- 分类导出测试确认源文件内容不变；任一类别数量不匹配时不会创建导出目录。
