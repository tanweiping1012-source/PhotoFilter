# 第一次筛选动态聚焦规格

## 问题

任务条只描述下一步，但没有把说明和真实控件建立视觉联系。用户双击照片进入大图后，必须自行寻找“保留”；完成导出后也只有关闭项目或“开始整理我的照片”，缺少明确结束教学的主操作。

## 动态聚焦

八步教学中的当前目标必须同时显示：

- 红色固定边框，包围可点击的真实控件或内容区域；
- 小指针固定在控件外侧，明确指向操作目标；
- 同一步内边框和指针不执行任何位置、尺寸、透明度或循环动画；
- 只有教学进入下一步时，整套聚焦提示才瞬时切换到下一个真实控件；
- 主边框使用控件内部的固定描边，禁止向外扩张、缩放或添加光晕；
- 不拦截鼠标、键盘或无障碍操作；

目标映射：

1. 选择人物：顶部“全部 / 人物 / 风景”三段选择。
2. 打开照片：当前选中的人物照片卡。
3. 人工保留：大图底部“保留”按钮。
4. 离线 AI评分：任务条中的“演示 AI评分”按钮。
5. 切换风景：离线 AI评分完成后自动关闭大图、返回照片网格，再指向顶部“全部 / 人物 / 风景”三段选择。
6. 查看评分：网格中先指向当前风景评分照片；打开大图后唯一目标转为任务条中的“评分已查看，继续”主按钮，点击后自动返回网格。
7. 确认结果：进入步骤时先恢复“全部照片”，任务条指向“显示评分优先照片”主按钮；点击后展示评分优先照片，并将目标转为底部“采纳评分结果”按钮。
8. 导出副本：底部“导出人物与风景 4 张”按钮。
9. 完成状态：任务条中的“结束新手引导”主按钮。

## 完成与退出

- 导出成功后进入明确的完成状态。
- “结束新手引导”是完成状态的主按钮，退出示例项目并恢复进入教学前的真实项目；没有真实项目时返回空白工作区。
- “开始整理我的照片”保留为次按钮，退出示例后打开文件夹选择器。
- 右上角关闭图标仍可随时提前退出，但不承担正常完成教学的职责。

## 验收

- 网格、大图、筛选、采纳、导出和完成按钮均接入统一聚焦组件。
- 第 5 步不会停留在不存在目标控件的大图页；评分结束后必须先自动返回网格。
- 第 7 步不要求用户理解或操作筛选菜单；任务条提供直接操作，并在展示结果后切换到采纳按钮。
- 完成状态可通过主按钮退出，不要求删除或关闭项目。
- 中英文 920×640 网格和 960×680 大图快照无重叠或截断。
