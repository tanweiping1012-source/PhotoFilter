# 新手引导规格

## 目标

首次安装后，用最短路径让用户理解并开始一次真实操作；不要求观看视频，不阻塞本地筛选，也不要求账号或 API Key。

## 首次启动

- 第一次正常启动自动展示新手引导。
- `--review-demo` 自动审核模式直接进入离线样例，不叠加首次引导。
- 用户关闭、选择样例练习或选择自己的照片后，记录当前引导版本；后续启动不再自动弹出。
- 侧栏始终保留“新手引导”入口，可随时重新打开。

## 场景首页

- 不再使用四页功能轮播。
- 首屏说明使用场景：旅行结束后，把同一天或同一段行程的人物和风景分开整理。
- 用一条流程概括“选择照片 → 分开类型 → 检查决定 → 可选 AI评分 → 确认保留 → 分类导出”。
- 真正的教学发生在照片网格和大图预览中，而不是继续阅读说明。

## 结束动作

- “体验一次完整筛选”：关闭引导并载入 4 张人物、4 张风景，通过八项真实界面任务完成第一次筛选。
- “选择我的照片”：关闭引导后打开系统文件夹选择器。
- “稍后再说”：关闭引导并保留空白工作区。

## 为什么不以视频为主

- 视频不能确认用户是否完成实际操作。
- 界面或文案变化后容易过期，双语字幕也增加维护成本。
- 示例筛选直接使用真实交互和业务状态，更适合学习预览、人工决定、查看评分和导出。
- 视频可在未来作为帮助页补充，但不作为首次启动的必经步骤。

## 边界

- 引导偏好仅保存版本号，不进入照片项目。
- 示例筛选从未评分状态开始；“演示 AI评分”按已评估照片数逐步写入人物和风景两套固定结果。
- 示例筛选继续不读取 Keychain、不联网、不持久化。
- 示例复用正式的人物/风景目标、分类评分、人工采纳和双目录导出逻辑。
- 完整任务与状态转换见 `FIRST_CURATION_GUIDE.md`。
