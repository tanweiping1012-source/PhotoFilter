# 第一次筛选教学规格

## 用户要理解什么

新用户完成教学后，应能回答三个问题：

1. 什么时候使用：旅行结束后，从同一天或同一段行程的大批照片中选出少量真正保留的照片。
2. App 如何协助：先在本机分开人物和风景并整理候选，需要时再按类型用 AI评分解释差异。
3. 谁做最终决定：AI 只评分，用户确认保留项，最后导出副本。

## 场景首页

首次启动不再轮播四页功能说明，只展示一个决策页面：

- 标题：“从一段旅程中，选出真正值得保留的照片”。
- 场景：旅行结束后，整理同一天或同一段行程中的相似照片和普通照片。
- 流程摘要：选择照片 → 分开人物/风景 → 检查决定 → 可选 AI评分 → 确认保留 → 分类导出。
- 主操作：“体验一次完整筛选”。
- 次操作：“选择我的照片”。
- 退出：“稍后再说”。

## 真实界面任务

体验入口载入 4 张人物、4 张风景和各 2 张保留目标，在真实照片网格中完成八项任务：

1. 在“照片类型”中选择人物，理解人物与风景分开整理。
2. 打开任意一张人物照片，理解大图检查。
3. 将实际打开的照片标记为保留，理解人工决定优先。
4. 主动运行“演示 AI评分”；按人物和风景分别应用固定结果。
5. AI评分完成后自动返回照片网格；点击顶部“风景”，理解两类照片拥有独立结果。
6. 查看一张风景照片的总分、五维评分、具体评价和总结，再点击明确的“评分已查看，继续”返回网格。
7. 点击任务条中的“显示评分优先照片”，检查后采纳人物和风景的其余结果。
8. 导出 4 张副本，确认输出包含人物和风景两个目录。

任务条是全宽界面带，不遮挡照片，不使用弹窗逐步打断。网格与大图预览共享同一教学状态。当前真实操作目标同时显示固定红框和固定小指针；同一步内没有动画，只有进入下一步时才瞬时切换到新目标。选择人物后不绑定固定照片，大图打开后聚焦立即转移到当前照片的“保留”操作。若下一步目标只存在于照片网格，教学会先自动关闭大图，避免任务条显示新步骤但页面上没有可操作目标。第 7 步不让用户自行理解筛选菜单，而是先恢复完整照片集，并提供“显示评分优先照片”直接操作。

## 离线演示边界

- 样例初始没有 AI评分结果，不再直接跳到完成态。
- “演示 AI评分”使用内置固定结果，复用正式 Validator 和 Applier，但不生成网络请求。
- 运行期间明确显示“离线演示”，不读取 Keychain，不消耗 API 额度。
- 评分按照片数量逐步出现，但人物和风景使用不同 scope 并在各自类别内排序；完成 8 张后才生成两类“评分优先”集合。
- 人工保留照片直接计入人物目标；人物和风景分别按独立分数补足各自 2 张，采纳后总数仍恰好为 4 张。
- 人工保留、采纳结果和复制导出继续使用正式业务路径。
- 教学状态、评分结果和样例决定均不持久化。

## 完成与退出

- 导出成功后显示教学完成，“结束新手引导”作为主按钮退出示例并恢复原工作区；“开始整理我的照片”作为次按钮直接进入真实文件夹选择。
- 用户可随时退出示例筛选；退出不会改变真实项目。
- 首次引导版本升级，已看过旧引导的用户会看到新版场景首页一次。
