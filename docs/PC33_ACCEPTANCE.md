# PC-33 AI 独立评分与全局排序验收

## 交付结果

- 评分契约升级为 `v2`，模型响应不再包含 `rank`。
- 方舟、MiniMax、Anthropic 和 OpenAI-compatible 共用 Prompt 均要求按固定绝对标尺逐张独立评分。
- Prompt 明确多图只是传输窗口，并禁止图片间比较、请求内名次和“本组 / 相比 / 优先 / 候补”等相对评价。
- 本地 Validator 会拦截模型偶尔返回的相对评价并触发现有格式重试，不会把该文案展示给用户。
- 所有候选完成后，App 按总分、五维分和稳定并列规则执行一次全局排序。
- “评分优先”取全局前 N 张；人工保留照片继续优先计入保留目标。
- 大图仅在完整一轮结束后显示“全局第 N 名”，单独评分显示“独立评分”。

## 请求与失败边界

- 每次请求仍发送 2–5 张无元数据 JPEG，但各照片互不比较。
- 48 张候选现在使用 10 个传输窗口，不再为 12 个保留名额创建 12 个局部晋级组。
- 任一照片缺少有效评分时，不生成不完整的最终结果。
- 同一轮锁定模型、接口和图片尺寸；固定标尺降低跨请求漂移，但不保证不同模型或多次运行的绝对分数完全一致。
