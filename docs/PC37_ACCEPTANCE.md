# PC-37 人物主题本地识别验收

## 交付结果

- “人物”语义改为人物承担主要视觉主题，不再因画面中出现任意人体或人脸就归为人物。
- 分类器采用两条人物成立路径：
  - 清晰正/侧脸或大比例人物主体；
  - 在风景构图中具有显著视觉权重的背影、逆光人物或剪影。
- 远处小脸、零散路人、背景人群、极端边缘人体和不显著小人继续归为风景。
- 人工人物/风景纠正、持久化、双目标、分类评分和双目录导出保持不变。

## 本地算法

- 快速阶段：完整人体框 + 人脸捕获质量 revision 3。
- 边界阶段：快速人物语义分割 + macOS 14 人物实例分割。
- 显著性阶段：仅在分割发现有效人物后，使用注意力显著区域确认人物是否承担视觉主题。
- 纯规则层根据面积、主导性、人脸质量、侧脸角度、实例数量、显著性重合和边缘位置作出决定。
- 无脸人体框必须得到人物分割佐证；纯分割剪影还必须具有实例证据、竖向人形比例并避开左右极端边缘。
- 显著性同时校验人物区域被覆盖比例和人物在显著区域中的占比，避免大范围显著框让自然物误报成立。
- 全部信号只在后台本机处理，不联网、不识别身份、不持久化自动证据。

## 回归覆盖

- 小路人归风景。
- 清晰正脸和清晰侧脸归人物。
- 大比例无脸人物归人物。
- 显著人物风景和仅靠分割发现的剪影归人物。
- 不显著小人、背景人群、合并人群分割和极端边缘剪影归风景。
- 无实例的纯分割、横向分割、无分割佐证的大人体框和低集中度显著区域归风景。
- 后台自动分析继续不能覆盖用户人工分类。
