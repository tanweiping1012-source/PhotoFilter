# MVP 产品说明

目标是让用户在本地快速浏览旅行照片、识别画面相似照片、提示清晰度/反差/曝光风险、手动标记保留或淘汰，并将保留项安全复制到新文件夹。

画面相似关系和技术风险用于生成候选家族与比较顺序；它们不改变照片的人工决定。时间只辅助边界画面相似判断和时间线排序，不能单独把照片定义为相似。可选 AI 只接收用户确认后的匿名低清预览，且不修改任何源文件。导出是复制操作，并需要用户确认。

导入后，App 先显示可浏览的照片网格；EXIF、相似图和技术风险在后台逐步完成。用户可在分析过程中开始手动选片，后到的分析结果不会覆盖人工决定。

照片在后台通过本机 Apple Vision 自动分为人物和风景。“人物”要求人物承担主要视觉主题：清晰正/侧脸、大比例人物主体，或在风景中具有明确视觉权重的人物/剪影；远处路人和背景人群仍归为风景。分类只用于整理，用户可在照片卡或大图中纠正。主界面使用“全部 / 人物 / 风景”三段选择切换照片范围，现有照片状态筛选继续独立工作。

用户分别设置人物和风景的精选数量，默认总数 12 张拆为人物 6 张、风景 6 张。当前版本仅在两类保留数都恰好达到各自目标时允许导出，避免一类照片挤占另一类名额。

相似照片会在后台按清晰度、反差与极端曝光风险生成内部技术顺序，用于压缩待评分池。这个中间顺序不判断构图、人物状态、情绪或发布价值，不在界面展示，也不改变用户的人工决定。

当本地分析完成后，App 会为人物和风景分别生成仅存在于内存的待评分池。画面高度相似，或画面中等相似且时间接近的照片先形成候选家族，每个家族只输出一个本地技术代表；已有人工保留照片的家族不再输出其他成员。普通照片全部具备参选资格，并按旅途时间线分段抽样。每类待评分池按该类剩余目标的 2–3 倍弹性收敛，而不是强制凑满 48 张；每个剩余保留名额仍最多 5 张，人工淘汰项绝不会进入。生成待评分池不会读取 Keychain、重编码图片或发起网络请求。

AI 对待评分池中的每张照片使用同一绝对标尺独立评分，但人物和风景使用不同的观察重点。人物评分关注表情、姿态、互动、人物清晰度及环境关系；风景评分关注空间层次、构图、光线、氛围与地点叙事。每次请求只携带 2–5 张同类型照片，这只是传输窗口，不形成组内比较或局部胜者。全部候选成功后，App 只在当前类型内按总分和五维分执行全局排序，取该类前 N 张进入“评分优先”；任一请求失败时不会生成该类型的不完整最终结果。

AI评分运行进度始终按已评估照片数量展示；人物和风景分别保留完成、暂停或失败状态，不向用户暴露内部请求切分。

左侧是可新建、切换和删除的项目列表；照片网格顶部先以“全部 / 人物 / 风景”选择类型，再用唯一状态筛选框选择“全部照片 / 待AI评分 / 已AI评分 / 评分优先 / 保留 / 淘汰 / 待定”。窗口底部固定显示人工决定、撤销、采纳评分结果和导出操作。所有筛选只改变可见范围，不删除、移动或修改原图。一次导出会在同一时间戳目录中生成“人物”和“风景”两个子目录。

照片卡用于快速扫描；已评分卡片只显示总分。双击卡片、按空格、点击顶部预览或“查看评分”可进入只读大图检查。大图预览沿当前筛选结果连续切换，并集中展示相似照片位置、技术风险，以及 AI 总分、五维评分、具体评价和总结；人工决定与底部命令共享同一 ViewModel 状态。AI评分只保留侧栏中的完整候选池入口，不提供单组相似照片局部评分。

发行版本采用 BYOK：本地筛选、人工决定与安全导出不依赖云端；需要 AI评分时，用户先选择品牌，再选择该品牌下支持图片输入的具体模型、评分图片尺寸并提供对应 API Key。内置覆盖火山方舟、MiniMax、OpenAI、Anthropic、Google Gemini、阿里百炼、xAI、Kimi、智谱 GLM、腾讯混元与自定义 OpenAI-compatible 接口。OpenAI 与 Anthropic 可读取账号可见模型 ID，也允许手动输入其他 model ID；发现结果仍需图片验证。新 Key 使用 1 张内置测试图验证鉴权、模型权限、图片输入和正式评分契约后才保存；验证可能产生少量供应商费用。App 不销售、代充或跳转购买 API Key，各品牌 Key 使用独立 macOS Keychain 条目。跨启动项目只持久化安全书签、相对路径人工决定、人物/风景目标和用户分类纠正；自动分类证据、照片、缩略图与评分图片不落盘。

AI评分设置是侧栏中的全局入口，不要求先创建照片项目；样例练习中隐藏该入口，以保持练习模式不读取 Keychain。项目侧栏中的 AI评分区只展示当前模型、待评分数量和运行状态，不提供第二个设置入口。

侧栏底部提供始终可访问的“隐私与数据”入口，明确本地处理、持久化字段、所选供应商 Authorization、预览图发送范围、账号关联、无跟踪声明和删除方式。隐私清单对用户确认后发送的预览图和供应商账号标识按“App 功能、关联用户、不跟踪”保守披露；文件时间戳只用于用户明确授权目录内的本地时间线排序，并辅助判断画面中等相似照片是否来自同一场景。

首次正常启动展示一次“第一次筛选”场景首页，也可从侧栏随时重开。首页说明旅行结束后整理同一天或同一段行程照片的使用场景，并允许直接选择自己的照片或体验完整示例筛选。示例使用 4 张人物和 4 张风景，在真实照片网格中完成八项任务：选择人物、打开大图、人工保留、离线分类评分、切换风景、查看评分解释、采纳评分优先照片和分类复制导出。8 张样例初始没有评分，只有用户主动运行演示后才按人物和风景分别写入通过正式契约校验的固定结果。示例不打开文件夹选择器、不读取 Keychain、不访问用户项目或网络，也不进入项目持久化；人工决定、采纳和复制导出继续使用正式业务路径。内部 `--review-demo` 自动审核模式直接进入第一次筛选任务，不叠加首次弹窗。
