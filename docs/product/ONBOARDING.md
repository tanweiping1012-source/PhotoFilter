# 新手引导规格

首次启动的场景首页、八步"第一次筛选"教学和教学期间的动态聚焦，是同一件事的三个部分，
放在一起定义，避免三份文档各说各话。

## 目标

首次安装后用最短路径让用户理解并**开始一次真实操作**：不要求看视频，不阻塞本地筛选，
也不要求账号或 API Key。用户完成教学后应能回答三个问题：

1. 什么时候用：旅行结束后，从同一天或同一段行程的大批照片中选出少量真正保留的。
2. App 怎么帮忙：先在本机分开人物和风景并整理候选，需要时再按类型用 AI评分解释差异。
3. 谁做决定：AI 只评分，用户确认保留，最后导出副本。

## 首次启动

- 第一次正常启动自动展示引导；`--review-demo` 自动审核模式直接进入离线样例，不叠加首次弹窗。
- 用户关闭、选择样例练习或选择自己的照片后记录当前引导版本，后续启动不再自动弹出。
- 侧栏始终保留"新手引导"入口，可随时重开。引导偏好只保存版本号，不进入照片项目。

## 场景首页

不使用功能轮播，只有一个决策页面：

- 标题："从一段旅程中，选出真正值得保留的照片"。
- 场景：旅行结束后，整理同一天或同一段行程中的相似照片和普通照片。
- 流程摘要：选择照片 → 分开人物/风景 → 检查决定 → 可选 AI评分 → 确认保留 → 分类导出。
- 主操作"体验一次完整筛选"、次操作"选择我的照片"、退出"稍后再说"。

真正的教学发生在照片网格和大图预览中，而不是继续阅读说明。

## 八步真实界面任务

体验入口载入 4 张人物、4 张风景，目标各 2 张，在真实网格中完成八项任务。
每一步同时给出任务描述和一个动态聚焦目标：

| 步骤 | 任务 | 聚焦目标 |
|---|---|---|
| 1 | 在"照片类型"中选择人物 | 顶部"全部 / 人物 / 风景"三段选择 |
| 2 | 打开任意一张人物照片查看大图 | 当前选中的人物照片卡 |
| 3 | 把实际打开的那张标记为保留 | 大图底部"保留"按钮 |
| 4 | 运行离线 AI评分 | 任务条中的"演示 AI评分"按钮 |
| 5 | 切换到风景，理解两类独立 | 先自动关闭大图返回网格，再指向三段选择 |
| 6 | 查看一张风景照片的评分详情 | 先指向该照片，打开大图后转为"评分已查看，继续" |
| 7 | 采纳人物和风景的评分结果 | 先恢复"全部照片"，指向"显示 AI 评分结果"，再转为底部"采纳" |
| 8 | 导出 4 张副本 | 底部命令条中的导出按钮 |
| 完成 | 结束教学 | 任务条中的"结束新手引导"主按钮 |

任务条是全宽界面带，不遮挡照片，不使用弹窗逐步打断；网格与大图共享同一教学状态。

## 动态聚焦

当前目标必须同时显示**红色固定边框**（包围真实控件或内容区域）和一个固定小指针（在控件外侧）。规则：

- 同一步内边框和指针不做任何位置、尺寸、透明度或循环动画；只有进入下一步才瞬时切换。
- 主边框使用控件内部的固定描边，禁止向外扩张、缩放或添加光晕。
- 不拦截鼠标、键盘或无障碍操作。
- 选择人物后不绑定固定照片；大图打开后聚焦立即转移到当前照片的"保留"。
- 若下一步目标只存在于照片网格，教学先自动关闭大图，避免任务条显示新步骤但页面上没有可操作目标。
- "照片筛选"是窗口级状态，进入示例时重置为"全部照片"，每一步开始前也会检查：
  当前筛选如果一张都筛不出来就自动退回"全部照片"——教学的任何一步都不允许出现空网格。
- 第 7 步不要求用户自行理解筛选菜单，任务条直接提供"显示 AI 评分结果"。

## 离线演示边界

- 样例初始没有 AI评分结果，不直接跳到完成态。
- "演示 AI评分"使用内置固定结果，复用正式 Validator 和 Applier，不产生网络请求。
- 运行期间明确显示"离线演示"，按已评估照片数量逐步出现（`离线演示 4 / 8 张`），
  人物和风景使用不同 scope 并在各自类别内排序；8 张全部完成后才生成两类 AI 推荐结果。
- 不读取 Keychain，不联网，不消耗 API 额度，不进入项目持久化。
- 人工保留照片直接计入人物目标；两类分别补足各自 2 张，采纳后总数恰好 4 张。
- 人工保留、采纳和复制导出继续走正式业务路径；教学状态、评分结果和样例决定均不持久化。

## 完成与退出

- 导出成功后进入明确的完成状态。
- **"结束新手引导"**是完成状态的主按钮，退出示例并恢复进入教学前的真实项目；
  没有真实项目时返回空白工作区。
- "开始整理我的照片"作为次按钮，退出示例后打开文件夹选择器。
- 右上角关闭图标仍可随时提前退出，但不承担正常完成教学的职责。
- 引导版本升级时，看过旧引导的用户会再看到一次新版场景首页。

## 为什么不以视频为主

视频无法确认用户是否完成实际操作，界面或文案变化后容易过期，双语字幕也增加维护成本。
示例筛选直接使用真实交互和业务状态，更适合学习预览、人工决定、查看评分和导出。
视频可以作为未来的帮助页补充，但不作为首次启动的必经步骤。

## 验收

- 网格、大图、筛选、采纳、导出和完成按钮均接入统一聚焦组件。
- 第 5 步不会停留在没有目标控件的大图页；第 7 步不要求用户操作筛选菜单。
- 完成状态可通过主按钮退出，不要求删除或关闭项目。
- 中英文 920×640 网格与 960×680 大图快照无重叠或截断。
