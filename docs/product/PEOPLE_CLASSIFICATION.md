# 人物主题本地分类规格

## 概念

“人物”不是“照片里含有人”，而是人物承担主要视觉主题。以下两类归为人物：

1. 清晰人像：一个或少量人物是主体，正脸或侧脸具有足够尺寸和可辨识质量。
2. 人物与风景：人物可以较小、背光或呈剪影，但人物在构图中具有明确视觉权重，并与环境共同表达主题。

街景中的远处路人、建筑旁偶然出现的小人、拥挤背景人群和不显著的人体检测结果继续归为风景。

## 本地信号

分类完全在本机使用 Apple Vision：

- `VNDetectHumanRectanglesRequest`：关闭 `upperBodyOnly`，取得完整人体框、面积和置信度。
- `VNDetectFaceCaptureQualityRequest`：取得人脸框、正/侧脸角度和 0–1 捕获质量；质量只作为支持证据，不单独决定分类。
- `VNGeneratePersonSegmentationRequest`：在人体检测不充分时取得人物像素覆盖和人物边界，补充逆光或剪影。
- `VNGeneratePersonInstanceMaskRequest`：统计独立人物数量，避免把背景人群合并成一个大人物区域。
- `VNGenerateAttentionBasedSaliencyImageRequest`：判断人物区域是否与人眼注意力热点重合。

不使用身份识别、相册人物聚类、云端模型或用户 API Key。

## 判定路径

### 清晰人像

满足以下组合时归为人物：

- 最大人脸至少占画面约 0.8%；
- 人脸在全部人脸中具有足够主导性；
- 人脸捕获质量不低于保守阈值，或人脸尺寸足够大以容忍侧脸质量波动；
- 对应人体框达到最低主体面积，或人脸本身达到强主体面积。

仅检测到很小的人脸不能成立。

### 主体人物

没有合格人脸时，最大人体框占画面约 10% 以上、在全部人体中占主导，并且人物语义分割与人体框有明确重合，才视为人物主题。人体框不能单独成立，避免礁石、树干等偶发人体框误报。

### 人物风景与剪影

人物较小时必须同时满足：

- 人物分割覆盖达到最低有效面积；
- 最大人物区域至少占画面约 1.8%；
- 最大人物在全部人物中占主导，避免背景人群；
- 人物区域大部分落在注意力显著对象内，同时人物至少占该显著对象约 10%，避免道路、建筑和夜景形成的大范围显著区域让背景路人成立；
- 人物不贴在画面极端边缘。

如果只有人物分割而没有人体框或人脸，还必须检测到人物实例，且分割框具有竖向人形比例并避开左右极端边缘。这条路径允许没有可见脸的背影、侧身和剪影，但不会因为海浪、飞鸟、交通灯或远处路人产生单一弱信号就自动成立。

## 性能

- 五个 Vision 请求共用同一个 `VNImageRequestHandler`，一次 `perform` 跑完，不再分阶段发起。
- 输入是流水线统一解码的 1024px 降采样图，不按原始分辨率重复解码。分类阈值全部按画面相对面积定义，在该尺度下与原图判断一致（实测 24 张真实照片一致率 100%）。
- 早期版本按"先人脸、命中就早退"分三次 `perform`，每次都重新解码整张原图；省下的那一两个请求远抵不过多出来的两次全分辨率解码。
- 全部工作在后台并行完成，扫描结果不会覆盖用户已纠正的类型。

## 用户控制

- 界面仍只显示“人物 / 风景”，不展示面积、阈值、显著性等技术术语。
- 照片卡菜单和大图继续允许人工纠正。
- 用户纠正优先于任何后续本地分析，并按相对路径保存。
- 自动证据与置信度只存在运行时内存，不进入项目文件或导出清单。

## 验收

- 单元测试覆盖：小路人、清晰人像、大比例无脸主体、显著剪影、非显著小人、背景人群，以及 9 张真实街景误判照片的脱敏 Vision 证据。
- Vision 采集层明确使用完整人体、人脸质量、人物分割和注意力显著区域。
- 人物主题规则为纯逻辑，可在不加载真实照片和不执行 Vision 的情况下测试。
- 现有人工纠正、双目标、分类评分和双目录导出行为保持不变。

## 收紧后的实测结果

街景误判收紧（PC-38）后在真实街景项目上完整复扫：人物 0 张、风景 159 张、读取失败 0 张。
即远处路人和背景人群不再被判为人物主题；该结果是本节阈值的验收基线，调整阈值时需重新复测。
