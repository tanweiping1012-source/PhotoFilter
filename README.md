# 旅行照片筛选器

本地优先的 macOS 旅行照片筛选器。第一版支持：把日期文件夹建立为会话项目、在本机分开人物与风景、识别画面相似照片、分别生成待评分池、保留/淘汰/恢复、撤销，以及将保留照片按人物和风景**复制**导出到新目录。

原图不会被移动、删除或改写。

## 运行

需要 macOS 14 或更新版本，以及 Xcode 26 / Swift 6.2。

```bash
cd photo-curator
scripts/run-app.sh
```

也可以直接打开 [PhotoCurator.xcodeproj](PhotoCurator.xcodeproj)，选择共享的 `PhotoCurator` Scheme 运行。该 Target 已启用 App Sandbox、安全书签、用户选择目录读写、出站网络与 Hardened Runtime。

若正在使用 App，又需要让开发者在不干扰当前窗口的情况下验证新版本界面，可启动隔离副本：

```bash
scripts/run-app.sh --verification
```

该模式每次使用独立应用标识，只用于本机验证，也不会干扰已打开的正式或旧验证窗口。

直接启动离线样例练习：

```bash
scripts/run-app.sh --verification --review-demo
```

示例从 4 张人物和 4 张风景的未评分程序化 JPEG 开始，并按类型逐步显示离线固定结果，不读取 Keychain、用户目录或网络。

构建本地 Release App 或创建 Xcode Archive：

```bash
scripts/package-app.sh
bash scripts/archive-app.sh
```

提交 App Store 前，仍需在 Xcode 中绑定 Apple Developer Team，并使用对应的发行证书完成 Archive 分发签名。

## 当前范围

- 支持 JPG、JPEG、PNG、WebP。
- 左侧以项目列表管理日期文件夹；可创建、切换和跨 App 重启恢复多个项目。项目仅通过只读 security-scoped bookmark 恢复授权，并保存目标数量与按相对路径记录的人工决定。删除项目只释放 App 状态和缩略图缓存，不删除原照片。
- 选择文件夹后递归扫描图片；只加载当前屏幕可见的缩略图。
- 缩略图在后台解码，内存缓存最多 120 张且约 96MB；项目删除会显式清空缓存。撤销只保存决定差异，不复制整份照片数组。
- 扫描后会先显示可浏览网格，再在后台逐步完成本地相似图和质量分析；重新选择文件夹会自动忽略上一轮尚未完成的结果。
- 使用 Apple Vision 在本机组合完整人体、人脸质量、人物分割和注意力显著性，将人物主题照与风景照分开。清晰人像和显著人物风景/剪影进入人物，远处路人和背景人群仍归为风景。照片卡菜单和大图均可纠正类型，人工纠正优先并按相对路径保存。
- 使用本地 8 × 8 灰度感知指纹识别画面相似照片；图片和指纹不会上传，也不进入导出清单。
- 优先使用 EXIF 拍摄时间（缺失时回退文件时间）进行时间线排序；只有画面中等相似时，时间接近才会提高同场景判断置信度，时间不能单独形成相似关系。
- 使用同一份本地低清灰度缩略图提示清晰度、低反差和严重曝光风险；风险仅供参考，绝不自动淘汰。
- 每个相似照片家族只允许一个“本地优先”代表进入待评分池，避免重复画面占用多个名额。排序仅依据清晰度、反差与曝光风险，不代表 AI评分结论。
- 没有相似关系的普通照片不会被忽略；它们全部具备参选资格，容量不足时按旅途时间线分段抽样，并在候选池中保留明确席位。
- 支持可选的多供应商 AI评分：先选择火山方舟、MiniMax、OpenAI、Anthropic、Google Gemini、阿里百炼、xAI、Kimi、智谱 GLM、腾讯混元或自定义兼容品牌，再选择该品牌下的视觉模型。OpenAI 与 Anthropic 可刷新账号模型并使用其他 model ID，不必等待 App 发版。API Key 使用内置测试图验证完整调用链路后，才独立保存到本机 Keychain。评分图片可选小 512px、中 1024px或大 1536px；每次最多发送 5 张无 EXIF/GPS 的匿名 JPEG，发送前确认品牌、模型、endpoint、尺寸和照片数量，绝不上传原始文件、文件名或路径。
- 双击照片卡、按空格或点击预览按钮可进入只读大图检查；左右切换当前筛选结果，并集中查看技术风险、本地排序与 AI 理由。
- App 会为人物和风景分别在本机生成待评分方案：相似照片优先，其余照片按时间线进入 2–5 张的传输窗口。人物评分关注表情、姿态和互动，风景评分关注空间层次、构图与光线；两类不会互相比较或挤占名额。
- AI 结果必须通过本地 JSON 契约校验才会显示为紫色建议；不会自动保留、淘汰、移动或导出照片。
- AI 胜者与人工保留照片合并后会再次做家族冲突审计；同一家族出现多张时，整轮最终结果不会生效。
- 左侧“新手引导”可进入一次完整示例筛选：选择人物、打开大图、人工保留、离线分类评分、切换风景、查看评分、采纳结果和分类复制导出；示例项目不持久化、不读取 Keychain、不联网或访问用户目录。
- 侧栏底部的“隐私与数据”始终可用，集中说明本地状态、AI 发送边界、第三方账号关联和删除方式；App Bundle 包含 `PrivacyInfo.xcprivacy`。
- 点击图片后，可用 `P` 保留、`X` 淘汰、`U` 恢复、`⌘Z` 撤销。
- 窗口底部始终显示撤销、恢复待定、淘汰、保留、采纳评分结果和导出按钮，不再依赖隐藏快捷键。
- 默认目标为人物 6 张、风景 6 张，可分别调整为 0–999 张；仅当两类保留数都恰好等于各自目标时才能复制导出。
- 导出前会显示目标位置与两类数量；只复制保留项到“人物”和“风景”两个子目录，并生成带类别的 `selection.json` 和 `selection.csv`。

HEIC/RAW 与更强的图像向量相似度将在后续里程碑实现。
